# /artifact skill and artifact link: repository copy first, in the thread language

Artifacts are linked from where the work is discussed. `artifact link <id> <#N|!N>` posts one comment: title, summary, the repository copy first as the source of truth, then the published site. It is written in the thread's language, Romanian without diacritics, and the ref is recorded in artifact.yaml. The /artifact skill covers new, build, verify and link, and the change request templates have an optional Artifacts section. Mirroring to external hosts is deferred: those links are personal, so the repository copy stays the one place to point at.
